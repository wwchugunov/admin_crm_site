# Проверка зависимостей — 20.10.2026

Проверены зафиксированные package-lock.json. В API и веб-приложении одна npm-зависимость — Nodemailer 10.1.0; сайт и его админка не имеют npm-зависимостей. Не обнаружены платные, proprietary, GPL/AGPL или неизвестные лицензии в этих lockfiles. Это проверка метаданных конкретных версий, а не гарантия для будущих обновлений.

Используются MIT, MIT-0, ISC, BSD-2/3-Clause, Apache-2.0, Python-2.0, BlueOak-1.0.0, 0BSD, WTFPL и разрешённые альтернативы MIT/CC0/ISC. Они допускают коммерческое использование с соблюдением соответствующих условий; сохранение уведомлений и текстов лицензий остаётся обязательным там, где это требует лицензия. Инструмент audit-licenses.cjs останавливает проверку при неизвестной/нерассмотренной лицензии; он не является автоматическим юридическим заключением.

Nodemailer 10.1.0 — MIT-0, платный EmailEngine не используется.

Docker Engine на VPS не требует покупки Docker Desktop. Docker Desktop на рабочем ПК имеет отдельные коммерческие условия: бесплатен для личного использования и малого бизнеса с менее 250 сотрудниками И выручкой менее $10 млн/год; при выходе за условия требуется подписка или альтернативный контейнерный runtime. Docker на ПК нужен только для локального запуска всех сервисов и интеграционных тестов. Контейнеры node/Debian/Alpine/Caddy содержат собственные открытые компоненты: сохраняйте лицензионные материалы образов. Npm-проверка не является полным SBOM образов.

Подключение Google, Telegram и SMTP регулируется условиями этих сервисов, квотами и тарифами. Платных UI-компонентов, веб-шрифтов с CDN или платных SDK в проверенных исходниках нет. Происхождение уже существующих иконок и иллюстраций не подтверждается лицензиями npm и требует учёта исходных материалов. Название LOMVIKO в интерфейсе не означает проверенную регистрацию/доступность товарного знака.

# LOMVIKO

CRM для бизнеса, который работает по записи: салоны, барбершопы, СТО, студии, репетиторы. Работает в браузере на компьютере и телефоне, ничего устанавливать не нужно.

[Запуск и обновление lomviko.com](33service/docs/PRODUCTION.md) · [Лицензии зависимостей](33service/docs/DEPENDENCIES.md)

| Адрес | Что это |
| --- | --- |
| https://lomviko.com | Сайт: описание, цена 399 грн/мес, регистрация, оферта и политики |
| https://app.lomviko.com | Веб-приложение CRM для владельца, администраторов и мастеров |
| https://lomviko.com/b/… | Страница онлайн-записи каждой компании |
| https://admin.lomviko.com | Админка продукта: клиенты, оплата подписок, почта, поддержка |
| https://site-admin.lomviko.com | Админка сайта: тексты, анонсы, заявки, документы |
| https://api.lomviko.com | API, Telegram-боты, вебхуки monobank и LiqPay |

```text

  api/          сервер API, боты, оплаты, почта
  core/         хранилище компаний, подписи запросов, интеграции
  shared/       общие для API и браузера переводы и правила ролей
  web/app/      веб-приложение app.lomviko.com
  web/admin/    админка продукта (index.html) и админка сайта (website.html)
  web/booking/  страница онлайн-записи
  worker/       Telegram-бот для собственного сервера компании
  deploy/       Dockerfile, compose, Caddy, manage.sh

33service/    всё служебное: тесты (tests), проверки и скрипты деплоя (tools), инструкции (docs)
compose.yaml  локальный запуск всех сервисов
```

## Локальный запуск

Нужен Docker с Compose:

```sh
docker compose up -d --build
```

| Сервис | Адрес |
| --- | --- |
| Сайт | http://127.0.0.1:4546 |
| Админка сайта | http://127.0.0.1:4547 |
| Админка продукта | http://127.0.0.1:4548 |
| Веб-приложение | http://127.0.0.1:4549 |
| API | http://127.0.0.1:4545 |

Порты меняются через `.env` (пример — `.env.example`). Данные хранятся в томе `ch-platform_api-data`.

Вход в админки — ключ администратора и одноразовый код:

```sh
sh 33service/tools/docker.sh credentials
sh 33service/tools/docker.sh code
```

## Проверки

Node.js 24 или новее. Перед первой проверкой установите зафиксированные зависимости: `npm ci --prefix platform` и `npm ci --prefix website`. Тесты лежат в `33service/tests`. Всё сразу: `npm run check` — проверка репозитория, лицензий и тесты сайта и платформы. Архив для сервера после коммита: `npm run prepare:deployment`.

## Как устроено

- Сервер API — единственный владелец данных: у каждой компании своя база, общий сервер хранит пользователей, подписки, письма и обращения.
- Веб-приложение — тонкий сервер (`platform/web/app-server.cjs`) поверх API: сессия в cookie HttpOnly, ключ браузера подписывает запросы к API.
- Сайт загружает публичные HTML, JS, CSS, изображения и шрифты в память при запуске; ETag позволяет браузеру проверять кеш без повторной передачи файлов. После изменения файлов в `website/public` перезапустите сервер сайта (в Docker — пересоберите и обновите контейнер). Публичные тексты и тарифы берутся из API: HTML-снимок обновляется раз в 30 секунд, браузер дополнительно проверяет актуальные данные. Сервер и браузер используют один рендерер `website/public/content.js`; при сбое API остаётся локализованный HTML с резервным содержимым.
- Регистрация с кодом на почту даёт 30 дней пробного периода. За 7, 3 и 1 день до конца и в день окончания приходит письмо; в приложении видно, сколько осталось. Оплату подписки подтверждает админ в «Користувачі → Підтвердити покупку», срок продлевается от конца текущего.
- Telegram-боты компаний, страницы записи и платежи monobank/LiqPay работают на сервере LOMVIKO; деньги клиентов идут напрямую на счёт компании.

Настольная версия LOMVIKO снята с поддержки и хранится только в архивном репозитории https://github.com/wwchugunov/CRM_BUES (тег `desktop-archive`).

# Проверка зависимостей — 15.10.2026

Проверены зафиксированные package-lock.json. В CRM 279 записей npm (включая инструменты сборки); в API одна — Nodemailer 10.1.0; сайт и его админка не имеют npm-зависимостей. Не обнаружены платные, proprietary, GPL/AGPL или неизвестные лицензии в этих lockfiles. Это проверка метаданных конкретных версий, а не гарантия для будущих обновлений.

Используются MIT, MIT-0, ISC, BSD-2/3-Clause, Apache-2.0, Python-2.0, BlueOak-1.0.0, 0BSD, WTFPL и разрешённые альтернативы MIT/CC0/ISC. Они допускают коммерческое использование с соблюдением соответствующих условий; сохранение уведомлений и текстов лицензий остаётся обязательным там, где это требует лицензия. Инструмент audit-licenses.cjs останавливает проверку при неизвестной/нерассмотренной лицензии; он не является автоматическим юридическим заключением.

Electron распространяется по MIT и включает Chromium/Node и сторонние компоненты с собственными лицензиями. В npm-отчёт содержимое бинарного Electron не входит. В установщик явно включены Electron-LICENSE.txt и полный поставляемый Electron файл LICENSES.chromium.html в resources/open-source. Не удаляйте их при распространении. Зависимости сборки не копируются в app.asar. В поставляемом LICENSES.chromium.html также есть тексты LGPL/GPL и альтернативных лицензий (например FFmpeg, glibc, WebKit, JSZip). Этот общий список включает материалы разных платформ и сам по себе не доказывает, что каждый компонент входит в конкретный установщик. Нельзя распространять вывод «нет GPL в npm» на весь бинарный Electron. Для компонентов с LGPL/исключениями нужны соответствующие условия распространения и доступность соответствующих исходников; одних npm-метаданных недостаточно. Перед коммерческим выпуском требуется проверка состава конкретных бинарников и выполнения этих обязательств. См. [условия FFmpeg](https://ffmpeg.org/legal.html).

Electron-builder — MIT; Nodemailer 10.1.0 — MIT-0, платный EmailEngine проект не используется.

Docker Engine на VPS не требует покупки Docker Desktop. Docker Desktop на рабочем ПК имеет отдельные коммерческие условия: бесплатен для личного использования и малого бизнеса с менее 250 сотрудниками И выручкой менее $10 млн/год; при выходе за условия требуется подписка или альтернативный контейнерный runtime. Для разработки CRM с production API Docker на ПК вообще не требуется; он нужен для изолированных интеграционных тестов. Контейнеры node/Debian/Alpine/Caddy содержат собственные открытые компоненты: сохраняйте лицензионные материалы образов. Npm-проверка не является полным SBOM образов.

Подключение Google, Telegram и SMTP регулируется условиями этих сервисов, квотами и тарифами. Платных UI-компонентов, веб-шрифтов с CDN или платных SDK в проверенных исходниках нет. Происхождение уже существующих иконок и иллюстраций не подтверждается лицензиями npm и требует учёта исходных материалов. Название BIZ в интерфейсе не означает проверенную регистрацию/доступность товарного знака.

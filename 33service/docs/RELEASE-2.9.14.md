# 2.9.14 — исправления по документу пользователя

Сайт 1.4.5. Источник: Google Docs `1889sUwdmDnw0aZNp1vW_W6Ps34WHgu5_onaxfKHFAUQ`, восемь заполненных пунктов.

- Регистрация и вход открываются поверх главной. Закрытие крестиком, кнопкой отмены или Escape сохраняет адрес и позицию страницы. После успешной авторизации открывается рабочий кабинет. Авторизация использует существующие формы приложения в iframe; встраивание разрешено только `https://lomviko.com`, сообщения проверяются по origin и source. Обычный кабинет сохраняет запрет встраивания. Метки рекламного перехода сохраняются.
- Выход открывает форму входа без кнопки регистрации в ней.
- Полный экспорт JSON/CSV и копия .orbit доступны только владельцу: запрет проверяется API, независимо от разрешения на настройки. В разделе объяснено назначение форматов, отсутствие самостоятельного полного импорта в другой вебаккаунт и отличие экспорта от серверной резервной копии. Выгрузка не продлевает подписку. Это не система предотвращения повторных регистраций.
- В разделе ПРРО объяснена цепочка «оплата → фискальный чек», отличие от приёма денег и риск двойного чека при одновременной фискализации в банке.
- Раздел Google-отзывов объясняет условия отправки запроса через подключённый Telegram-бот, самостоятельную публикацию клиентом и отсутствие импорта отзывов из Google.
- Карточка клиента шире, контакты и заметки выделены отдельно; день рождения сохранён. Добавлены необязательные именинные даты `ДД.ММ`, вводимые вручную. Валидация календаря, совместимость со старыми обновлениями/копиями и очистка при анонимизации проверены. Автоматические поздравления на именины не добавлялись.
- Подпись общей базы заменена на «Дані вашої компанії» с пояснением синхронизации и прав команды.
- Стрелки списков получили собственный отступ, включая часовой пояс записи.

Проверки: полный `npm run check`, серверные регрессии экспорта, хранения дат, защиты iframe и авторизации. Браузерные сценарии проверяются на боевых доменах; до выкладки изменяемые статические файлы подменяются только в тестовом браузере, после — проверяются опубликованные ответы без подмены. Изменения данных допускаются только в QA-компании.

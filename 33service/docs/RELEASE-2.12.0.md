# 2.12.0 — резервные копии в админке, сообщение о приостановке

- Админка → «Резервні копії»: сервер сам делает полную копию раз в сутки (все базы компаний и продукта, документы, ключи сервера; базы копируются на ходу через VACUUM INTO и проверяются quick_check), хранит последние 14 автоматических; копии вручную — «Створити копію зараз» — остаются до удаления. Каждую можно скачать (файл шифруется паролем владельца, AES-256-GCM) или удалить. Только для владельца админки.
- Восстановление: node tools/restore-server-backup.cjs <файл> <папка>.
- Приостановленный владельцем доступ показывает «Доступ тимчасово призупинено… info@lomviko.com», а не «Підписка закінчилась».

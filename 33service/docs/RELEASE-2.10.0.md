# 2.10.0 / сайт 1.5.0 — свободное время, форма услуги, отчёт Excel, оферта, главная

Источник: ТЗ владельца от 18 ноября 2026, пункты 1–9.

## Сайт
- Убрана надпись «Демонстрація сценарію · вигадані дані».
- «Перший онлайн-запис за три кроки»: Створіть послуги → Налаштуйте команду → Приймайте онлайн-записи, с настоящими экранами программы (демонстрационная компания).
- «Своя сторінка запису»: на телефоне — слайдер из четырёх экранов (послуга, спеціаліст, дата і час, підтвердження) со свайпом, точками и кнопкой «Далі»; на компьютере — полная страница.
- «Зараз усе безкоштовно»: функции сеткой карточек, неполный последний ряд по центру; тарифные карточки тоже по центру.

## Программа
- Услуга: тип «Індивідуальна» / «Групова» (места только у групповой), «Хто виконує» — список с галочками, кабинет или оборудование, «Додатково»: пауза після запису, спеціалістів на один запис.
- Сотрудник: специалист или кабинет/оборудование; свои часы работы и перерыв.
- Свободное время: часы и перерывы каждого, смены, отсутствия, пауза после визитов, кабинеты; «будь-хто вільний» назначает наименее занятого; групповые занятия принимают клиентов, пока есть места. Кабинеты не показываются клиентам как специалисты.
- Звіт у Excel (.xlsx) за день, тиждень, місяць або свої дати: «Загальна статистика», «Співробітники», «Записи». Доступ — право «Фінансовий звіт». Кнопка CSV заменена отчётом; JSON-выгрузка осталась.
- «Публічна оферта» и «Умови користування» — отдельные кнопки, каждая видна только когда её документ включён, и открывает свой документ.
- Скрытые части форм больше не показываются (поля сменного графика при «Дні тижня»).

Существующие данные не меняются: новые столбцы добавляются со значениями по умолчанию (все ресурсы — специалисты, пауза 0, свои часы не заданы).

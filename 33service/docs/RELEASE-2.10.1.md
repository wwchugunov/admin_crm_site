# 2.10.1 / сайт 1.5.2 — быстрое окно регистрации и входа, кеш программы

- Окно «Спробувати» / «Увійти» на сайте открывает отдельную страницу app.lomviko.com/auth только с формами (регистрация, код из письма, вход, восстановление пароля): около 21 КБ и 7 запросов вместо всей программы (около 660 КБ и 39 запросов). Вызовы сервера те же, после успеха кабинет открывается без повторного входа; учёт регистрации в Google Ads сохранён.
- Пока форма грузится, окно показывает LOMVIKO и индикатор; загрузка начинается при наведении на кнопку.
- Скрипты и стили программы получают отпечаток содержимого (?v=…) и кешируются браузером на год; при новой версии отпечаток меняется. Повторное открытие кабинета больше не перепроверяет каждый файл.
- Встраивать в окно разрешено только /auth и прежний /?embed=1 и только с lomviko.com.

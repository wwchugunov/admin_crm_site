# 2.9.15 — формы входа и регистрации без запуска кабинета

Исправлена регрессия 2.9.14: при сохранённой сессии окно на главной загружало CRM и автоматически переходило в кабинет. Фоновая загрузка и обновления могли менять содержимое окна.

Встроенные страницы теперь запускают только форму, выбранную кнопкой: регистрацию для «Спробувати» и вход для «Увійти». Они не запрашивают снимок CRM, поддержку и согласия текущего аккаунта, не запускают рабочий интерфейс и не завершают существующую сессию. Повторное обновление не заменяет форму. Кабинет открывается вне окна только после явного успешного входа, подтверждения регистрации или восстановления пароля.

Обычный кабинет и его обновления сохранены. Учёт подтверждённой регистрации вызывается перед переходом; метки перехода сохраняются.

Регрессии проверяют обе формы при сохранённой сессии и без неё, отсутствие запросов CRM, стабильность после 15-секундного обновления, закрытие без навигации, сохранение исходной сессии и явный вход с переходом в отдельный кабинет.

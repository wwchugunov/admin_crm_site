# 2.9.11 / сайт 1.4.4 — исправления аудита от 17.11.2026

Статус: версия 2.9.11 / сайт 1.4.4 опубликованы 17.11.2026.

- Сервер фильтрует снимки и историю по правам: закрытые клиентские карточки,
  телефоны и цены не передаются сотруднику. Для расписания остаются имена и ID
  клиентов с визитами/ожиданием; клиенты без визитов не включаются без права clients.
- Ревизия снимка учитывает права и роль. Отзыв прав заставляет приложение получить
  новый снимок, очистить ранее загруженную историю и закрыть старую форму.
- Мобильные интеграции помещаются в ширину экрана. Исправлены длинные адреса
  и flex-basis, создававший большие пустые вертикальные отступы.
- Добавлена отдельная настраиваемая конверсия подтверждённой регистрации.
  До получения метки цели из Google Ads она выключена. Заявки и регистрации
  не смешиваются. Linker настраивается до config по документации Google.

Проверки: npm run check — 173 теста платформы, 16 сайта; проверки репозитория
и лицензий. В тестовом Chrome на боевой HTML-странице с новым CSS: ширины
320, 390 и 1440 px, переполнения интеграций нет. Это проверка подготовленного
CSS, а не утверждение, что изменения уже опубликованы.

На сервере выполнены только проверки состояния и пробная распаковка старого
архива в изолированном контейнере с отключённой сетью. Архив от 09.11.2026:
14 SQLite-баз, PRAGMA quick_check без ошибок. Живой том не изменялся.
Нужно отдельно организовать свежие автоматические копии CRM вне VPS.

Патч 2.9.12: команды Google tag передаются в документированном формате arguments.
Проверка реальной отправки: endpoint googleadservices.com вернул 200 для метки
регистрации. В Google Ads создана отдельная цель; её метка задаётся в deploy/.env.

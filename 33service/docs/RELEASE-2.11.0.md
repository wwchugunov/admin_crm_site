# 2.11.0 — услуга и специалист по-новому, постоянные клиенты

- Услуга: ціна, тривалість, час відпочинку після послуги, коментар. Остальное (групова з місцями, кабінет, спеціалістів на запис, передоплата, відсоток, матеріали, де показувати) — в «Додатково».
- Спеціаліст: ПІБ, додаткова інформація, які послуги виконує (галочки), постійні клієнти. Услуга, у которой никто не выбран, считается доступной всем; снятие галочки у одного оставляет её остальным.
- Постійні клієнти: после двух записей к одному специалисту клиент становится постоянным сам; вручную можно добавить из списка клиентов или убрать. При записи в программе специалист подставляется сам; на сайте и в боте «Будь-хто вільний» отдаёт клиента его специалисту, если тот свободен.
- Восстановление старых резервных копий: недостающие новые поля берут значения по умолчанию.

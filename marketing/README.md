# Маркетинговые материалы LOMVIKO

Исходники презентации и черновиков юридических документов. Готовые файлы публикуются не из Git, а загрузкой в админки (раздел «Документи»), поэтому их можно заменить в любой момент без выпуска новой версии сайта.

## Презентация (15 слайдов, UA и EN)

```sh
npm run presentation              # обе версии
npm run presentation -- uk        # только украинская
CONTACT_EMAIL=hello@lomviko.com npm run presentation   # email на последнем слайде
PREVIEW=1 npm run presentation    # дополнительно PNG каждого слайда
```

Результат: `.runtime/presentation/LOMVIKO-presentation-uk.pdf` и `-en.pdf`. Нужны Google Chrome и `playwright-core` (ищется в этом репозитории; иначе `npm i --no-save playwright-core` или переменная `PLAYWRIGHT_CORE`).

- Тексты: `presentation/content.cjs`. Вёрстка: `presentation/build.cjs`, стили: `presentation/presentation.css` (шрифты и цвета общие с сайтом).
- Скриншот приложения на слайде 14: `presentation/assets/app.png`. После редизайна CRM замените файл и пересоберите.
- Загрузка: админка сайта → «Документи» → «Презентація LOMVIKO». На сайте появится блок с кнопкой, короткие адреса `lomviko.com/presentation` и `/en/presentation`.

## Политики конфиденциальности и оферта

```sh
npm run legal
```

Создаёт PDF и DOCX в `.runtime/legal/` из `legal/*.uk.html`. Это **черновики**: заполните поля в квадратных скобках (реквизиты, провайдеры, сроки), согласуйте с юристом и удалите блок «ЧЕРНЕТКА».

| Документ | Где загрузить | Где показывается |
| --- | --- | --- |
| Политика сайта | Админка сайта → Документи | Подвал сайта, ссылка у формы заявки, `lomviko.com/privacy` |
| Публичная оферта | Админка сайта → Документи | Подвал сайта, `lomviko.com/offer` |
| Политика приложения | Админка приложения → Документи | CRM: Налаштування → Правові документи; ссылка в форме регистрации |

Принимаются PDF, DOC и DOCX до 25 МБ; тип проверяется по содержимому файла. Новая версия сразу становится текущей, прежние остаются в архиве: их можно вернуть или удалить. Если английской версии нет, англоязычные посетители получают украинскую. Пока документ не загружен, ссылки на него скрыты. Файлы хранятся на сервере в `/data/documents` — включайте этот каталог в резервные копии.
